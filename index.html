Algorithms & data structures

Animal record sorting

Grazioso Salvare dashboard.

I wrote a Python merge sort and added controls to sort animal records by age, name, or breed.

  • Equal values keep their original order.
  • Missing or invalid values stay last in either direction.
  • Six checks cover fields, directions, and edge cases without changing the input list.
6.032 ms merge sort vs. 99.534 ms bubble sort
1,500 synthetic records · median of 5 runs

Benchmark details

Merge sort uses O(n log n) time and O(n) auxiliary memory. The benchmark compares my implementation with bubble sort on generated records. It does not show an improvement over Python’s built-in sorting or the original dashboard’s table sorting.
