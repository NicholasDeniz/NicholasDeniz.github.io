Travlr Getaways

A booking experience with clear boundaries.

I extended an existing travel application with customer bookings and separate customer and admin roles, connecting the interface, API, and database.

  • Server-side role checks protect trip management.
  • Customers create, view, and cancel their own bookings.

Algorithms & data structures

A more deliberate sort.

Custom merge sort for an animal rescue dashboard.

I implemented a reusable Python merge sort and connected it to Dash controls for sorting animal records by age, name, or breed.

  • Equal values keep their original order.
  • Missing or invalid values stay last in either direction.
  • Six checks cover fields, directions, and edge cases without changing the input list.
6.032 msmerge sort vs. 99.534 ms bubble sort
1,500 synthetic records · median of 5 runs

Benchmark & tradeoffs

Merge sort uses O(n log n) time and O(n) auxiliary memory. The benchmark compares my implementation with bubble sort on generated records. It does not show an improvement over Python’s built-in sorting or the original dashboard’s table sorting.

A measurable improvement to MongoDB retrieval.

I extended the rescue dashboard with database pagination, selected fields, validated filters, and a compound index for the rescue query.

  • Retrieve 10 records per page instead of loading all matches.
  • Validate fields, operators, page sizes, and age ranges.
  • Compare query plans and save evidence before and after indexing.
